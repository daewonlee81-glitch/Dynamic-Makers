# MAX-E1 강화학습 키트 (3단계)

다이나믹 메이커스 3D 탭과 **같은 MuJoCo 모델·같은 걸음 공식·같은 신경망 계산**을 쓰는 Python 학습 키트입니다.
여기서 학습한 정책 파일(`policy.json`)을 앱의 **3D 탭 → 3. 강화학습 정책 → [정책 파일 열기]**로 불러오면
3D 가상 로봇과 실제 MAX-E1에서 그대로 동작합니다.

## 준비
```bash
pip install -r requirements.txt      # mujoco, numpy (그래픽카드 필요 없음)
```

## 학습
```bash
python train_es.py                   # 약 60번 반복, 2코어 PC에서 6분 정도 → policy.json
python train_es.py --project 내프로그램.dmk   # 앱의 [걸음 학습]으로 찾은 걸음에서 시작
python train_es.py --eval policy.json        # 걸음만 vs 걸음+정책 비교 (밀기·무게·마찰을 바꾼 20개 세계)
```

예시 결과 (`example-policy.json`, STEP 부품 조립 모델, 2코어 6분 학습, 밀기·무게·마찰을 바꾼 20개 세계):

| | 넘어짐 (20회 중) | 간 거리 (평균) |
|---|---|---|
| 걸음만 | 6회 | 138 cm |
| 걸음 + 정책 | 2회 | 280 cm |

기본 걸음은 `python search_gait.py`(여러 세계에서 버티는 걸음 찾기)로 찾은 것입니다.

## 무엇을 학습하나요?
- **걸음 공식**(7개 숫자: 주기·무릎 굽힘·옆 흔들기·발 들기·보폭·위상·팔 흔들기)이 기본 리듬을 만듭니다.
- **신경망**(입력 18 → 은닉 32 → 출력 12)은 CM-550 기울기 센서(좌우·앞뒤 기울기, 회전 속도), 걸음 위상,
  직전 관절 목표를 보고 12개 관절에 작은 보정(최대 ±0.25 rad)을 더합니다.
- **보상:** 앞으로 간 거리 + 버틴 시간 − 옆으로 벗어남 − 넘어짐 − 몸 기울기 − 보정 크기.
- **진화 전략(ES):** 신경망을 조금씩 다르게 바꾼 복사본 24개를 같은 세계(같은 밀기)에서 걸려 보고,
  잘 걸은 쪽으로 신경망을 옮깁니다. 역전파·GPU가 필요 없어 교실 PC에서도 돌아갑니다.
- **세계 바꾸기(도메인 랜덤화):** 매번 무게 ±15%, 마찰 ±30%, 모터 단단함 ±20%, 옆에서 1~3.5 N 밀기를 무작위로 줍니다.
  실제 로봇은 모델과 똑같지 않으므로, 여러 세계에서 버티는 정책이 실제 로봇에서도 더 잘 버팁니다.

## 파일
| 파일 | 내용 |
|---|---|
| `maxe1.xml` | MuJoCo 모델 (앱의 3D 탭 [모델 파일 받기]로 내 로봇 설정에 맞춘 것으로 교체) |
| `cad-measurements.json` | ROBOTIS STEP 도면에서 잰 부품 크기·부피 (모델 치수·무게의 근거) |
| `maxe1-map.json` | 관절 ↔ 다이나믹셀 ID·방향·가운데 각도, 모델 치수 |
| `maxe1_env.py` | 학습 환경 (걸음 공식·제어 주기 25 Hz·모터 속도 6 rad/s·IMU 관측) |
| `train_es.py` | 학습·평가 스크립트 |
| `search_gait.py` | 걸음 공식 7개 숫자 찾기 (교차 엔트로피, 여러 세계에서 평가) |
| `example-policy.json` | 예시 정책 |

## 주의
- ID 배치(1·2, 3·4 어깨 / 5·6, 7·8 엉덩이 / 9·10, 11·12 발목 모듈)는 조립서 4·39쪽과 같습니다.
  모델은 ROBOTIS STEP 부품을 조립서대로 조립한 것에서 관절 위치·무게·관성을 계산했습니다(앱의 `scripts/maxe1_asm.py`, 약 1.2 kg).
  모듈 안에서 어느 축(A·B)이 앞뒤/옆인지와 회전 방향은 아직 실제 로봇으로 확인해야 합니다.
- 시뮬레이터와 실제 로봇은 다릅니다(기어 유격, 통신 지연, 바닥). 실제 로봇은 손으로 받칠 수 있게 하고
  짧게(3~5초) 시험한 뒤 늘리세요. 블루투스는 센서를 읽는 간격이 길어 USB를 권합니다.
- PPO 같은 다른 강화학습 알고리즘을 쓰려면 `MaxE1Walk.rollout()`을 기준으로 단계별 환경을 만들면 됩니다
  (관측 18개·행동 12개·제어 주기 0.04초를 그대로 지키면 앱에서 같은 정책 파일 형식으로 불러올 수 있습니다).
