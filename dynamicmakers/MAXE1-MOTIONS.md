# MAX-E1 공식 예제 모션 번호와 동작

출처: ROBOTIS ENGINEER Kit 1 MAX-E1 예제 모션 파일 (03_ENG1_MAX_E1.mtn3), © ROBOTIS.
번호는 CM-550에 내려받은 모션 번호(예제 태스크의 `(로봇종류-1)×100 + n`, 휴머노이드는 로봇종류 2)와 같습니다.
오른/왼은 로봇 자신의 오른쪽·왼쪽입니다. 시간은 모션 파일 기준(1프레임 = 1/128초)입니다.

걷기는 시작 → 반복 → 끝 을 멈춤 없이 이어야 합니다: 블록 "모션 [150] 번 시작 → [152] 번 [초] 동안 반복 → [154] 번 끝".
