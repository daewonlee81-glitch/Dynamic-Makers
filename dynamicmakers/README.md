# 다이나믹 메이커스 (Dynamic Makers) — RoboMakers

ROBOTIS **CM-550 + 다이나믹셀(XL-330 / XL-430 / 2XL-430)** 전용 워드블럭 코딩 앱입니다.
Scratch 3 블록 모양과 실행 엔진을 쓰되 무대·스프라이트 없이 **블록 + 실시간 Python** 화면으로 구성했습니다
(Pybricks Code와 같은 방식).

```
┌ 로고 · 프로그램 이름 · 새로 만들기 / 열기 / 저장 / .py 저장 ·· 연결 상태 · USB / 블루투스 · ▶ 실행 ■ 정지 ┐
│ 분류 │ 블록 목록 │        블록 작업 영역          │  Python (실시간 · 읽기 전용) │
└───────────────── 출력 창 ('말하기' 블록, 연결·오류 메시지) ─────────────────┘
```

## 블록 분류
| 분류 | 내용 |
|---|---|
| 이벤트 | 실행(깃발) 클릭했을 때, 키를 눌렀을 때, 신호 보내기/받기 |
| 제어 | 기다리기, 반복, 무한 반복, 만약/아니면, ~까지 기다리기/반복, 멈추기 |
| **다이나믹셀** | 각도 이동(동시 이동·기다리기), 바퀴 회전, 정지, 토크, 모드, LED, 상태 읽기, ID 목록 |
| **컨트롤러** | CM-550 LED·부저·버튼·기울기·자이로·가속도·소리·전압·온도·다이나믹셀 전원 |
| **센서·포트** | 5핀 포트 센서(IR·거리·터치·밝기·컬러 등), LED 모듈, 서보, 기어모터 |
| **모션** | R+ Task로 저장한 모션 재생·정지·속도·다음 페이지 |
| **자세** | 관절 힘 빼기/주기, 지금 자세 기록, 자세 n번으로 움직이기, 모두 차례로, 개수, 지우기 |
| **AI 학습** | AI가 [종류]를 알아봤을 때, 알아본 것, [종류]인가?, 확신 정도(%), 인식 켜기/끄기 |
| **몸 동작** | 사람이 보이는가?, 사람의 [관절] 각도, [손·발·코] 위치, 다이나믹셀이 사람의 [관절] 따라 하기, 추적 켜기/끄기 |
| 연산 · 변수 · 내 블록 | Scratch와 동일 (내 블록 입력값 이름은 값1·조건1 처럼 한글) |
| 출력·타이머 | 말하기(→ 출력 창, Python `print`), 타이머, 키 눌림 |
| 고급 | 컨트롤 테이블 주소 직접 읽기/쓰기, 프로그램 안에서 연결/끊기 |

## 모터 종류 자동 인식
연결하면 바로 다이나믹셀을 검색(브로드캐스트 핑)해 모델에 맞춰 자동으로 처리합니다.
- **ID 메뉴:** 블록의 ID 드롭다운에 검색된 모터가 모델·축과 함께 먼저 나옵니다(`3 · 2XL430 A축`). 다른 번호도 그대로 선택 가능.
  이미 놓인 블록의 표시도 검색 후 바뀝니다.
- **연결된 모터 분류:** 연결된 모터 종류에 맞는 블록만 보여 줍니다.
  2XL430/2XC430 → `다이나믹셀 2축 모듈 [모듈] A축/B축 이동`, `… 바퀴`; XL330·XC330·XM430·XH430(전류 제어) → `… 힘 [%] 로 [deg]° 까지 잡기`; 공통 → `모델 이름`.
- **동작 자동 맞춤:** 이미 맞는 모드면 EEPROM을 다시 쓰지 않음, 2축 모듈은 A/B축 짝(연속 ID)을 찾아 설정 변경 시 다른 축 토크를 잠시 해제 후 복원,
  전류 제어가 없는 모델에 '잡기'를 쓰면 안내, 지원하지 않는 모델(XL-320 등) 차단,
  XL330 같은 5 V 모터가 CM-550 배터리 전압 버스에 있으면 손상 경고.
- 블록에서 나는 오류는 출력 창에 ⚠ 로 표시됩니다.

## 자세 가르치기 (가르치기 탭)
로봇을 손으로 움직여 동작을 가르칩니다(MAX-E1 같은 휴머노이드에 맞춤).
1. **관절 힘 빼기:** 로봇을 받친 채 모든 관절 또는 고른 관절(예: 팔만)의 토크를 끕니다.
2. **기록:** 손으로 자세를 만들고 스페이스 키(또는 버튼) → 모든 관절 각도가 `로봇 자세` 리스트에 한 줄로 저장됩니다(프로젝트와 함께 저장).
3. **재생:** 자세마다 [n초]로 이동, 처음부터 재생, 덮어쓰기·지우기, **블록으로 만들기**(깃발 → 자세 1 → 자세 2 … 블록을 넣어 줌).
- 힘을 다시 줄 때 목표 위치를 현재 위치로 먼저 맞추므로 로봇이 예전 자세로 튀지 않습니다.
- 자세 이동은 관절마다 이동 거리에 맞춰 속도를 정해 **모든 관절이 동시에 도착**합니다.

## AI 학습 (AI 학습 탭)
Teachable Machine처럼 예시를 보여 주며 AI를 학습시키고, 결과로 로봇을 움직입니다. 모든 계산은 PC 브라우저 안에서 하며 인터넷이 필요 없습니다.
- **입력:** 📷 카메라(내장 MobileNet이 장면을 숫자 256개로 바꿈) · 🎤 소리(32개 음높이 대역의 크기) · 🤖 로봇 센서(CM-550 기울기·회전·가속도).
- **학습:** 종류 이름을 정하고 [누르고 있는 동안 모으기]를 꾹 누르면 예시가 모입니다(종류마다 20개 이상 권장). 바로 실시간 결과와 확률 막대가 보입니다.
- **블록:** `AI가 [종류] 을(를) 알아봤을 때` 등. [예시 블록 만들기]가 종류마다 "알아봤을 때 → 말하기"를 넣어 줍니다. ▶ 실행 시 인식이 자동으로 켜집니다.
- 분류는 k-최근접 이웃(가장 비슷한 예시들의 투표), 확신 60% 미만이면 "잘 모르겠어요". 예시(사진이 아닌 숫자)는 프로젝트 파일에 함께 저장됩니다.
- 카메라 사진·소리는 저장되지 않습니다. 웹 버전은 AI 모듈(`dm-ai.js`, 1.3 MB)을 AI 학습을 처음 켤 때만 불러옵니다.
- MobileNet 가중치: Google, Apache License 2.0 (`scripts/gen-ai-model.py`로 다시 만들 수 있음).

## 몸 동작 (스켈레톤)
PC 카메라로 사람의 관절 17곳을 찾아(MoveNet, 앱에 내장, 인터넷 불필요) 로봇을 움직입니다.
- **AI 학습 탭 → 🧍 몸 동작:** 영상 위에 스켈레톤을 그리고 양 어깨·팔꿈치·무릎·몸·머리 각도를 실시간으로 보여 줍니다.
- **자세 학습:** 같은 탭에서 만세·팔 벌리기·앉기 등 몸 자세를 종류별로 모아 학습(관절 위치를 어깨 폭 기준으로 정규화 → 서 있는 위치·거리와 무관).
- **따라 하기:** `다이나믹셀 [ID] 이(가) 사람의 [오른쪽 어깨] 따라 하기 (가운데 180°, 같은 방향)` — 목표 각도 = 가운데 ± 사람 관절 각도.
  [따라 하기 예시 블록]이 "깃발 → 무한 반복 { 모터 a ← 오른쪽 어깨, 모터 b ← 왼쪽 어깨(반대 방향) }"를 넣어 줍니다(ID·가운데·방향은 로봇에 맞게 수정).
- 각도 기준: 어깨 = 팔 내림 0° · 옆 90° · 위 180°, 팔꿈치·무릎 = 펴면 0°, 기울기 = 사람의 왼쪽으로 +. 왼쪽·오른쪽은 사람 기준.
- ▶ 실행 시 몸 동작 블록이 있으면 카메라가 자동으로 켜지고, ■ 정지하면 꺼집니다. 2° 미만의 변화는 모터에 보내지 않아 통신량을 줄입니다.
- 웹 버전은 모델 파일 `dm-pose.js`(6 MB)를 몸 동작을 처음 켤 때만 불러옵니다. MoveNet: Google, Apache License 2.0 (`scripts/gen-pose-model.py`).

## 모니터
상단의 **Python | 모니터 | 가르치기 | AI 학습** 전환 버튼으로 오른쪽 화면을 모니터로 바꿉니다. 연결 후 자동으로 다이나믹셀을 검색합니다.
- **컨트롤러:** 연결 방식, 모델·펌웨어, 배터리 전압(10.5 V 미만이면 빨간색), 온도, 기울기, 버튼, 다이나믹셀 전원, 저장된 모션 수.
- **다이나믹셀:** ID, 모델명, 현재 각도, 온도, 전압, 토크(눌러서 켜기/끄기 — 끄면 손으로 돌리며 각도 확인), 상태(정상/움직이는 중/하드웨어 오류).
  검색은 Protocol 2.0 브로드캐스트 핑 한 번, 응답이 없으면 ID 1~30을 하나씩 확인합니다.
- **포트 번호에 대해:** CM-550의 다이나믹셀 포트 6개는 한 버스에 병렬 연결이라 어느 포트에 꽂혔는지는 알 수 없습니다.
  **찾기** 버튼으로 해당 ID의 LED를 깜빡여 위치를 확인합니다.
- **센서 포트 1~5:** 센서 종류를 고르면(자동 인식 불가) 실시간 값을 표시합니다. 선택은 브라우저에 기억됩니다.
- **진단:** 다이나믹셀이 안 보이면 자동으로 실행됩니다(헤더의 [진단]으로 직접 실행 가능). 입력 전압(6.5 V 미만 = USB 전원만),
  다이나믹셀 전원 스위치(주소 22, [전원 켜기] 제공), 통신 속도(주소 12), 모드·바이패스 포트, CM-550 자체 검색(주소 40→39),
  앱의 중계 핑과 받은 원본 바이트를 차례로 확인해 원인과 조치를 한국어로 보여 주고 [결과 복사]를 제공합니다.
- 갱신 주기: USB 0.5초, 블루투스 1.2초. 프로그램 실행 중에는 통신이 겹치지 않도록 일시 정지합니다.

## 가상 로봇
상단의 **가상 로봇** 버튼은 CM-550 + 다이나믹셀 4개(ID 1~4, XL430)를 흉내 내는 시뮬레이터에 연결합니다.
로봇이 할 동작(`🤖 다이나믹셀 1 → 90°`, `CM-550 초록 LED 켜기`, `모션 3번 재생` …)이 출력 창에 표시되고,
센서 값은 천천히 변하는 가짜 값, '이동하고 기다리기'·'모션 재생하고 기다리기'는 실제처럼 시간이 걸립니다.
로봇 없이 수업하거나 USB를 쓸 수 없는 화면(claude.ai 미리보기 등)에서 시험할 때 사용합니다.

## 사용
1. Chrome 또는 Edge로 앱을 엽니다 (Web Serial / Web Bluetooth 필요).
2. **USB 연결**(또는 블루투스 연결) → 포트 선택. 상태가 "USB 연결됨"으로 바뀝니다.
3. 블록을 조립하고 **▶ 실행**. 실행 중인 블록 묶음은 노랗게 빛나고, **■ 정지**로 멈춥니다.
   블록 하나를 클릭해도 바로 실행됩니다.
4. **저장**은 `.dmk` 파일(프로그램), **.py 저장**은 Python 코드. **열기**는 `.dmk`·`.json`과 Scratch `.sb3`를 엽니다.
   claude.ai 미리보기 안에서는 저장 형식 제한 때문에 프로그램은 `.json`, Python은 `.txt`로 저장됩니다.
   작업 내용은 브라우저에 자동 저장되어 새로고침해도 이어집니다.

## 빌드 · 배포
정적 파일만 있으면 되므로 학원 서버, GitHub Pages, 사내 NAS 등 어디에나 올릴 수 있습니다
(USB/블루투스 API 때문에 **https** 또는 `localhost` 에서 열어야 합니다).

세 가지 빌드가 있습니다. **PC에서 더블클릭으로 쓰는 실행본**은 `MODE=file` 입니다.

```bash
MODE=file npm run build   # → dist-file/ : DynamicMakers.html(약 8 MB, 오프라인) + 실행기(Windows .bat, macOS .command) + README.txt
```
`file://` 로 열어도 Chrome/Edge에서 보안 컨텍스트라 USB(Web Serial)가 동작합니다. 실행기는 Chrome(없으면 Edge)을 앱 창(`--app`)으로 띄웁니다.

나머지 두 빌드:

| | `MODE=web` (기본) | `MODE=local` |
|---|---|---|
| 블록 라이브러리·실행 엔진 | cdn.jsdelivr.net에서 불러옴 (scratch-blocks 2.2.1, @scratch/scratch-vm 15.3.0) | dist/ 안에 포함 |
| dist/ 크기 | 3개 파일, 약 220 KB (이 앱의 코드만) | 약 8 MB |
| 용도 | 인터넷 되는 곳 어디든, claude.ai 미리보기 | 인터넷 없는 학원 내부망 |

```bash
# scratch-editor 체크아웃의 node_modules 에서 scratch-blocks 를 사용 (SCRATCH_EDITOR=경로)
npm install
npm run build                          # MODE=web
MODE=local npm run build               # 오프라인용 (scratch-vm 웹 빌드 필요)
npm run serve                          # http://localhost:8700
npm test                               # 가짜 USB CM-550 + 가상 로봇 E2E 20항목
node test/monitor-check.js <URL>       # 모니터 12항목
node test/diagnose-check.js <URL>      # 진단 6항목 (가상 로봇 고장 모드: 저전압·전원 꺼짐·중계 안 됨)
node test/dual-axis-check.js <URL>     # 2XL430 축 잠금 회귀 4항목
node test/models-check.js <URL>        # 모터 종류 자동 인식 14항목 (window.__dmSimModels 로 모델 구성)
```

CM-550 블록은 엔진에 내장하지 않고, 앱이 시작할 때 엔진에 등록합니다(일반 npm 엔진을 그대로 사용).
엄격한 보안 정책(eval 금지) 화면에서도 프로그램을 불러오도록 엔진의 검증 단계를 건너뛰는 대체 경로가 있습니다.

## 소스 구성
```
src/main.js      엔진·블록 연결, 상단바(연결/실행/파일), 출력 창, 키보드 입력
src/toolbox.js   블록 분류 구성 (로봇 블록은 opcode별로 5개 분류에 배치)
src/theme.js     색상 (브랜드 블루 #2E6ABF)
src/dialogs.js   이름 입력 창, 내 블록 만들기 창, 확인 창
src/project.js   빈 프로젝트, 파일 열기/저장, 자동 저장
src/sim-robot.js 가상 로봇 (Protocol 2.0 시뮬레이터)
src/monitor.js   모니터 (컨트롤러·다이나믹셀 ID·센서 포트 실시간 표시)
src/media.js     블록 아이콘을 페이지 안에 내장 (scripts/gen-media.js 가 생성)
public/          index.html, CSS, 로고
test/            가짜 CM-550(USB) + E2E 테스트
../scratch-cm550/src  CM-550 통신·블록 확장·Python 변환기 (공용)
```

## 라이선스 주의
* **scratch-blocks** (블록 그래픽): Apache-2.0 — 상업적 사용 자유.
* **scratch-vm** (실행 엔진, 현재 버전 15.x): **AGPL-3.0**. 이 엔진을 포함한 앱을 웹으로 학생에게 제공하면
