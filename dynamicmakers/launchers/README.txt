다이나믹 메이커스 (Dynamic Makers) - RoboMakers
================================================

[실행 방법]
  Windows : DynamicMakers-Windows.bat 를 더블클릭
  macOS   : DynamicMakers-Mac.command 를 더블클릭
            (처음 한 번은 "확인되지 않은 개발자" 경고가 나올 수 있습니다.
             이때는 파일을 Control+클릭 → [열기] 를 선택하세요.)
  직접 열기: DynamicMakers.html 을 Chrome 또는 Edge 로 끌어다 놓아도 됩니다.

  - 인터넷 연결 없이 동작합니다 (모든 기능이 HTML 파일 하나에 들어 있음).
  - 이 폴더의 파일들은 함께 두세요. 폴더 위치는 어디든 괜찮습니다.

[로봇 연결]
  1. CM-550 을 USB 케이블로 PC에 연결하고 전원을 켭니다.
  2. 상단의 [USB 연결] → 목록에서 CM-550 포트를 선택합니다.
     (블루투스: CM-550 MODE 버튼으로 블루투스 모드를 켠 뒤 [블루투스 연결])
  3. 블록을 조립하고 [▶ 실행] 을 누릅니다.
  로봇이 없으면 [가상 로봇] 으로 시험할 수 있습니다.

[모니터]
  상단의 [Python | 모니터] 에서 [모니터] 를 누르면 연결된 CM-550 상태와
  다이나믹셀 ID·모델·각도·온도·전압, 센서 포트 값을 실시간으로 볼 수 있습니다.
  - 다이나믹셀 포트 6개는 서로 연결된 하나의 통로라 "몇 번 포트"인지는 알 수 없습니다.
    [찾기] 를 누르면 그 ID의 모터 LED가 깜빡여 어느 모터인지 확인할 수 있습니다.
  - 토크 버튼으로 힘을 빼면 손으로 관절을 돌리며 각도를 확인할 수 있습니다.
  - 센서 포트는 꽂은 센서 종류를 직접 골라야 값이 나옵니다.
  - 다이나믹셀이 안 보이면 [진단] 이 원인(배터리 미연결, 전원 꺼짐, 통신 속도 등)을
    알려 줍니다. 해결되지 않으면 [결과 복사] 내용을 보내 주세요.
  - 다이나믹셀은 배터리 또는 12V 어댑터가 있어야 동작합니다 (USB 전원만으로는 안 됨).

[저장]
  [저장] 은 .dmk 파일, [.py 저장] 은 Python 파일로 내려받습니다.
  작업 내용은 브라우저에 자동 저장되어 다시 열면 이어서 할 수 있습니다.
  (자동 저장은 이 파일 위치 기준이라, 파일을 다른 폴더로 옮기면 새로 시작됩니다.
   중요한 프로그램은 꼭 [저장] 하세요.)

[USB 포트가 목록에 안 보이면]
  - USB 케이블이 충전 전용이 아닌지, CM-550 전원이 켜져 있는지 확인하세요.
  - R+ Manager / R+ Task 등 다른 프로그램이 같은 포트를 쓰고 있으면 먼저 닫으세요.
